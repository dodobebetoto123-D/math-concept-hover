## 06 평행선 사이의 선분의 길이의 비
- 06-1 삼각형에서 평행선 사이의 비: BC//DE이면 AB:AD = AC:AE = BC:DE / AD:DB = AE:EC. 역도 성립 (비례하면 평행)
  → 인터랙티브: 점 D를 변 AB 위에서 슬라이더로 이동, DE는 BC와 평행 유지, 세 비가 실시간으로 같게 유지되는지 표시
- 06-2 삼각형의 각의 이등분선: 내각 이등분 AB:AC = BD:CD / 외각 이등분도 AB:AC = BD:CD (외분점)
  → 인터랙티브: 내각/외각 토글, 교점 D 위치 변화 + 비 고정 표시
- 06-3 평행한 세 직선 l//m//n이 두 직선과 만날 때 a:b = c:d
  → 인터랙티브: 평행선 간격 + transversal 기울기 슬라이더, 기울기를 바꿔도 비 유지
- 06-4 사다리꼴 AD//EF//BC, AD=a, BC=b, AE=m, EB=n이면 EF = (an+bm)/(m+n)
  → 인터랙티브: m:n 슬라이더로 E 위치 이동, EF 길이 실시간 계산
- 06-5 응용: AB//EF//DC, AB=a, CD=b이면 BF:FC = a:b, EF = ab/(a+b)
  → 인터랙티브: a, b 슬라이더, EF가 a,b 둘 다보다 짧아지는 것 시각화

## 07 삼각형의 무게중심
- 07-1 중점연결정리: AM=MB, AN=NC이면 MN//BC, MN = (1/2)BC. 역도 성립
  → 인터랙티브: 삼각형 꼭짓점 드래그, MN 길이와 BC 길이 비 1:2 상시 표시
- 07-2 무게중심: 세 중선은 한 점(무게중심 G)에서 만나고, G는 각 중선을 꼭짓점으로부터 2:1로 나눈다
  → 인터랙티브: 꼭짓점 드래그해도 세 중선이 한 점에서 만남 + AG:GD = 2:1 숫자 표시
- 07-3 무게중심과 넓이: 세 중선으로 나뉜 6개 삼각형의 넓이는 모두 같다 (= 전체의 1/6)
  → 인터랙티브: 6조각 색칠 토글, 각 조각 넓이 숫자 동일하게 표시

## 08 닮음의 활용
- 08-1 닮은 도형의 비: 닮음비 m:n이면 둘레의 비 m:n, 넓이의 비 m²:n² / 입체 겉넓이 m²:n², 부피 m³:n³
  → 인터랙티브: 닮음비 k 슬라이더 (1~3), 길이 k배·넓이 k²배·부피 k³배가 벌어지는 차이 그래프
- 08-2 닮음의 활용: 그림자+AA닮음으로 건물 높이 구하기 / 축도·축척 = 축도 길이 ÷ 실제 길이
  → 인터랙티브: 막대 높이·그림자 길이 슬라이더 → 건물 높이 자동 계산 / 지도 줌으로 축척 체험

## 09 피타고라스 정리
- 09-1 정리: 직각삼각형에서 a² + b² = c² (c는 빗변)
  → 인터랙티브: a, b 슬라이더, 각 변 정사각형 면적 칸으로 a²+b²=c² 표시
- 09-2 증명: 닮음을 이용한 증명 (a²=c×DB, b²=c×AD), 유클리드 증명 (정사각형 넓이 이동)
- 09-3 증명/조건: 바스카라식 증명 (직각삼각형 4개 재배열), 직각삼각형이 되기 위한 조건 a²+b²=c²
  → 인터랙티브 (09-2/3 공통): 조각 재배열을 단계 버튼(Step)으로 재생하는 증명 애니메이션
- 09-4 변과 각의 관계: 가장 긴 변 c에 대해 c² < a²+b²이면 예각, =이면 직각, >이면 둔각삼각형
  + 직각삼각형 성질 DE²+BC² = BE²+CD² / 대각선 직교 사각형 AB²+CD² = BC²+DA²
  → 인터랙티브: 변 c 슬라이더로 예각↔직각↔둔각 전환 + 실시간 판정 배지
- 09-5 활용: 세 반원 S₁+S₂ = S₃, 히포크라테스의 달 넓이 = 직각삼각형 넓이
  → 인터랙티브: 삼각형 크기 변경에도 S₁+S₂=S₃ 유지 표시, 달 모양 색칠

## 10 경우의 수 (p.120)
- 10-1 사건과 경우의 수: 사건이 일어나는 경우의 가짓수. 빠짐없이, 중복되지 않게 구한다
- 10-2 A 또는 B (동시에 일어나지 않을 때): m + n — 합의 법칙
- 10-3 A와 B 동시에: m × n — 곱의 법칙
  → 인터랙티브 (10-1~3 공통): 동전+주사위 tree 그림. '또는'이면 가지 합치기(더하기), '동시에'이면 가지 곱해지기(격자)를 같은 화면에서 전환
- 10-4 일렬로 세우기: n명 → n×(n-1)×…×1 / n명 중 2명 뽑아 세우기 n(n-1), 3명 n(n-1)(n-2) / 이웃하게 세우기: 이웃한 것을 하나로 묶기 × 묶음 내부 자리바꿈
  → 인터랙티브: 사람 카드 드래그로 줄 세우기, 인원 추가 시 경우의 수 폭발 표시, '이웃 묶기' 토글
- 10-5 자연수의 개수: 0 없으면 2자리 n(n-1), 3자리 n(n-1)(n-2) / 0 있으면 맨 앞자리 0 불가 → 2자리 (n-1)(n-1), 3자리 (n-1)(n-1)(n-2)
  → 인터랙티브: 숫자 카드 + 0 포함 토글, 앞자리 제한으로 개수가 줄어드는 과정 표시
- 10-6 대표 뽑기: 자격이 다르면 (순서 있음) n(n-1) / 자격이 같으면 (순서 없음) n(n-1)/2, 3명은 / (3×2×1)
  → 인터랙티브: 자격 같음/다름 토글 — 순서만 다른 쌍이 하나로 합쳐지는 애니메이션

## 11 확률 (p.134)
- 11-1 확률의 뜻: p = (사건 A가 일어나는 경우의 수 a) / (모든 경우의 수 n). 도형 확률 = 부분 넓이 / 전체 넓이
- 11-2 기본 성질: 0 ≤ p ≤ 1, 절대 일어나지 않으면 0, 반드시 일어나면 1
  → 인터랙티브 (11-1/2 공통): 주사위·룰렛 클릭, p = a/n 분수 표시 + 0~1 게이지
- 11-3 일어나지 않을 확률: 1 − p ('~가 아닐', '적어도 ~일' 표현에서 사용)
  → 인터랙티브: 전체 막대에서 사건 부분을 빼는 시각화
- 11-4 A 또는 B 확률 (동시에 일어나지 않을 때): p + q
- 11-5 A와 B 동시에 확률 (서로 영향 없을 때): p × q
  → 인터랙티브 (11-4/5 공통): 10-2/10-3과 같은 UI 재사용, 동전+주사위 동시 던지기 예시 (1/2 × 3/6 = 1/4)
- 11-6 연속하여 꺼내기: 다시 넣으면 처음/나중 확률 같음 / 다시 넣지 않으면 다름 (조건 변화)
  → 인터랙티브: 공 꺼내기 + '다시 넣기' ON/OFF 토글, 두 번째 뽑기 확률의 분모·분자 변화 표시
